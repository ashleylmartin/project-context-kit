# Interview Me

Thin pointer. Take whatever plan/design/idea prompted this as the seed for
the initial decision tree, then run `../frontier-interview/SKILL.md` in
full (Steps 1–5). Once the frontier is empty and the user has confirmed the
resolved tree, just report it back as the session's output — this skill
doesn't write anything to a doc itself (for that, use `interview-with-docs`
instead).
